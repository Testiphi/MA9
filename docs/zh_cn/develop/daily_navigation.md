# 每日赛事导航首版

## 使用

在 Maa Pipeline Support 控制面板重新加载项目任务，选择安卓端、连接 MuMu，使用现有 resource 资源。

- `选中每日赛事（含奖励）`：主页未选中时点击底部每日赛事，确认白底黑字后结束；已经选中时直接结束。支持当前有奖励、无奖励两种截图。
- `进入每日赛事（仅无奖励，样例页验证）`：必要时先切换标签，只有选中标签和“探索赛事”按钮同时命中才再次点击底部导航。验证截图里的“限时充值奖励”标题和右上主页图标后结束。发现选中标签和“领取”按钮时执行 StopTask，停在主页；这不代表已经进入赛事页。

普通任务 MyTask1 也已接到定位入口。其他模板任务仍是示例，不用于导航验证。

## 实测顺序

1. 在单人模式主页运行定位任务，确认切到每日赛事后停止。
2. 已选中每日赛事时再运行定位任务，确认没有进入页面。
3. 无奖励时运行进入任务，分别测试从单人模式主页开始、从每日赛事已选中开始。
4. 有奖励时运行定位任务；运行进入任务应停在每日赛事选中状态，最后命中“每日赛事_有奖励暂停”。
5. 遇到失败，保存当前框架完整截图和 Maa 日志，查看最后命中的节点。不要只凭任务显示完成判断到达。

不需要领取奖励来完成这次验证。暂未实现返回主页、弹窗关闭、未解锁识别和自动领奖。

## 适用范围

模板来自 captures 中五张 1280x720 原图。固定中文界面及短边 720；更改比例或语言需要重新标定。And 使用内联子识别，需要 MaaFramework >= 5.3。纯模板匹配无需 OCR 模型或 Python Agent。

进入页标题模板是当前样例的特征，不是所有每日赛事页面的通用特征。赛事内容、默认选中卡片改变或自动跳转到领奖页面时，到达验证可能超时；此时应补充截图再扩展目标页识别。任务没有无条件点击回退，单次标签切换、进入点击最多各执行一次。

## 离线检查

以下操作不控制模拟器：

```powershell
python -X utf8 tools/prepare_daily_navigation.py
python -X utf8 tools/check_daily_navigation.py
python -X utf8 tools/validate_schema.py --schema-dir deps/tools
```

裁图依赖 Pillow；截图检查依赖 numpy、opencv-python；配置校验依赖 tools/requirements.txt 的相关包。
检查报告输出为 captures/daily_navigation_check.json。五张截图的分支均通过，但截图来自模板源，只能证明当前样例的分支一致性，不能替代 Maa 运行时与 MuMu 点击实测。
