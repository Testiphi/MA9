多人循环每局先读取经典系列赛首页“我的评级分”左侧徽章，再进入选车。

| 页面 | 能确认什么 | 用途 |
|---|---|---|
| 系列赛首页评级徽章 | 玩家当前段位 | 每局唯一选车依据，不读取会变化的评级分数字 |
| 段位升级页 | 升级目标段位 | 点击继续，回到首页后重新确认 |
| 段位降级弹窗 | 左侧新段位，右侧旧段位 | 点击确定，回到首页后重新确认 |
| 选车列表顶部图标 | 列表当前定位段位 | 仅导航，不能确认玩家段位 |
| 车辆详情段位图标 | 车辆参赛要求 | 判断不可用；不能当作玩家段位 |

黄金推荐顺序为黄金→白银→青铜，白银为白银→青铜。推荐车全部不可用后，黄金从白金起点反向进入黄金末尾，白银从黄金起点反向进入白银末尾。详情向左遍历，跳过未拥有、缺油、不能参赛的车辆；青铜首车仍不可用则停止，防止环绕死循环。

升降级提示完成后下一局读取新段位，不再因降级暂停。黄金推荐或黄金兜底遇到黄金段位不可用时立即返回首页重新确认，避免遍历整个不可用段位。服务器错误仍在同一局以独立计数重排选车。

启动时若在列表或详情，会逐级返回系列赛首页读取徽章。识别到其他段位或无法确认时停止，避免盲选。当前只支持黄金、白银两种玩家段位。

生成：`python -X utf8 tools/prepare_dynamic_multiplayer_loop.py`。该命令分别生成两套独立轮次，再合并到 `assets/resource/pipeline/multiplayer_loop.json`。不要用旧的静态生成命令覆盖合并结果。
