# 经典系列赛选车准备

任务：`准备经典系列赛选车（开启仅拥有）`。

根据当前原图，实际路线为：主页切换多人 → 点击左侧经典系列赛卡片 → 赛事介绍页点击右下开始 → 车辆选择页 → 判断仅拥有开关 → 必要时开启 → 确认开启并结束。

本任务的“开始”点击只发生在有“经典系列赛 / 世界系列赛”标题的赛事介绍页，用于进入选车列表；车辆详情的开赛按钮不在本任务中。

支持从其他主页标签、多人主页、经典系列赛介绍页、选车页开始。选车页必须同时匹配车辆选择标题、段位图标条及开关状态才执行动作。已经开启仅拥有时不点击。任务不改变段位、不选择车辆、不处理弹窗、不实现返回。进入其他内页时会等待超时。

## 实测

在 Maa Pipeline Support 重新加载任务，选择安卓端和现有资源、连接 MuMu，仅执行此任务：

1. 从单人模式主页开始，应最终停在选车列表且仅拥有开启。
2. 从经典系列赛介绍页开始，应点击开始并进入选车列表。
3. 在选车页手动关闭仅拥有，再运行，应只开启开关。
4. 仅拥有开启后再运行，应保持原地。

成功结束节点为 `多人准备_仅拥有已开启`。用户已确认此准备任务在 MuMu 实测通过。失败时保存当前框架截图和 Maa 日志，查看最后命中节点。

## 返回主页

独立任务 `返回主页（房子按钮）`：识别右上房子后点击，再同时检查右上齿轮和六项标签中任意一项的选中状态，确认主页后结束。已经处于主页时直接结束，不点击齿轮。单次任务最多点击一次房子。

按用户说明，房子返回对应标签主页（多人选车返回多人标签），左上返回仅退到上一步；两者用途不同。当前返回任务确认到达主页，不额外切换标签，也不检查必须是哪一项选中。

18 张现有截图的返回分支离线检查与配置校验通过，实际点击需实测：从多人选车页运行应返回多人主页，再运行一次应保持原地。没有房子、也没有可确认主页的画面会超时结束，不进行坐标盲点。

## 验证与限制

用户已确认黄金定位和 TouchDrive 开启任务实测通过。进入多人介绍页、进入选车页及任务开始时的等待放宽到 60 秒。timeout 按时间而非固定识别次数计算；页面提前识别到即继续，不会固定等待一分钟。识别期间不重复点击开始，保留最多一次点击限制。超过 60 秒仍未识别到则失败并保留现场。

18 张当前原图的入口分支离线检查通过，包括无关每日赛事内页不命中任何分支；所有资源和 interface 配置校验通过。截图来自模板源，只能验证当前图像的分支区分，实际点击、转场和其他段位下的外观仍需设备实测。
