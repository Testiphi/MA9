# 主页切换与多人导航

六项主页切换资源位于 assets/resource/pipeline/home_navigation.json。新增界面任务：选中多人游戏、选中传奇通行证、选中赛季赛事、选中我的俱乐部、选中单人模式。每日赛事沿用已实测的选中任务。

每项任务只切换到主页对应标签并确认，已经选中时不点击。模板只裁按钮右侧文字及背景，避开左上通知标记。没有实现奖励状态检测；没有多人金色通知截图，不能据此宣称该状态已实测。当前账号的锁定状态不在本版覆盖范围。

## 验证

在 Maa Pipeline Support 刷新任务，连接 MuMu。先从单人模式运行“选中多人游戏”，应停在经典系列赛、试驾挑战、对决三张卡片的主页。再执行同一任务应保持原地。随后交替测试其他新增任务。只选择当前要验证的一个任务执行。

14 张主页截图、六个目标共 84 个离线分支检查通过；原有每日赛事截图检查和全部配置校验通过。这些是模板源截图检查，仍需模拟器实测点击和转场。

## 多人下一批截图

暂以左侧经典系列赛为第一条路线，若实际自动化目标是另一个模式应先改选路线。不要假设再次点击底部多人标签会选择某个系列赛，先手动点击目标卡片观察。

按实际出现页面保存到 captures，保持 1280x720 完整 PNG：

- 多人游戏_经典系列赛_进入后.png
- 多人游戏_选车.png（如果与进入后相同，无需重复）
- 多人游戏_车辆已选.png（拍到燃油、车辆状态和开始按钮）
- 多人游戏_匹配中.png（后续实际开赛时再补）
- 多人游戏_返回后.png

遇到额外确认或遮挡，补拍“多人游戏_具体提示名称.png”。第一轮只需进入、选车、返回的截图；不必为了导航采集进行比赛。匹配、比赛操作、结算与领奖是后续工作。
