# 对决（擂台）资格赛入口

对决是多人游戏首页右侧的独立卡片，与经典系列赛并列。任务 **对决（擂台）入口（资格赛或防守）** 从多人首页点击对决卡片：每周首次进入出现资格赛介绍页时点击右下角“资格赛”，平时直接到防守编队页时识别页面并结束。如果之前进入资格赛却一场都没打完，任务还会从“资格赛失利”页面重新开始资格赛。任务也可从这三种页面直接启动。它不接入经典系列赛的选车、比赛或结算循环。

素材 `captures/多人游戏_对决_主页卡片.png` 和 `captures/多人游戏_对决_首次进入_资格赛.png` 均为 1280×720。识别首页使用底部“多人游戏”已选中状态和卡片内的“对决”标题；不依赖会变化的倒计时和排名。资格赛页同时识别左上“对决”和右下“资格赛”，避免把“奖励”误点成入口。

资格赛防守编队有五个有序赛道格。`多人游戏_对决_资格赛_防守_第N赛道展开_未选车.png`（N=1～5）分别记录每个格展开时的画面；`多人游戏_对决_资格赛_防守_第1赛道展开_已选车_可开始.png` 记录配车后的橙色“开始”。大地图和小地图名称、路线形状、图标、倒计时与车辆都会变化，不参与状态识别。五个未选车状态分别用展开面板内绿色“选择车辆”的固定位置区分；可开始状态用右下橙色按钮区分，并共同校验左上“资格赛”标题。若已配一部分车辆、不符合这六种具体状态，则用“资格赛”标题和左下“自动选车”按钮确认已到防守页。**识别对决资格赛防守位置（只读）** 可单独验证这些状态，不会点击任何车辆、自动选车或开始。

资格赛中断的样例是五张赛道成绩全部为 `00:00.000` 的“资格赛失利”页面。入口任务同时核对该标题、五处零成绩和右下橙色“重新开始资格赛”，才点击重开；弹出确认框后再识别标题与中央绿色按钮，点击确认，清空当前资格赛进度，回到第一赛道未选车页面。已有任意成绩的中断页面不会进入这条自动重开分支。入口阶段不读取票券数字或倒计时；截图中的重开按钮标有 1 张票券，实际票券状态等进组后再识别。

五张图可分别运行 **对决资格赛：查看第 N 张图** 和 **对决资格赛：进入第 N 张图选车**。前者从当前展开位置点击目标小卡片并停留在其详细信息；后者接着点击该展开面板内的绿色“选择车辆”（已配车时是“更换车辆”），停在游戏的选车页面，不选具体车辆也不开赛。当前展开位置由绿色按钮的固定位置判断，不读取地图名、地图图标或车辆。可从五张图任意一张出发；R 级起点选车截图已纳入只读车辆识别，导航点击后的目标页面仍待实机确认。
