# J50 搜索测试

任务：`搜索Ferrari J50（黄金，开启TouchDrive，不开赛）`。

路线：主页切换多人 → 左侧经典系列赛 → 介绍页开始 → 选车页开启仅拥有 → 点击黄金回起点 → 查找完整可见的 Ferrari/J50 车型标识 → 未找到则滑动 → 点击标识 → 确认详情页 Ferrari/J50 → 确保 TouchDrive 开启 → 结束。

支持从主页、经典系列赛介绍页、选车列表或 J50 可开始详情页运行。实际车型、燃油、性能分未混入列表模板，点击目标使用实际命中的车型标识框，而非固定车辆坐标。不会点击车辆详情页的比赛开始按钮。J50 仅作为测试目标，不改正式轮换顺序。

滑动从 (1000,420) 到 (600,420)，320ms，动作前延迟 0，之后等待 350ms 再检查，最多 12 次。时序来自 `vehicle_search.swipe_timing()`，与两车和黄金轮换任务共用。每次优先检查 J50，找不到再滑动。耗尽上限后等待 5 秒再超时失败并保存现场；目前未实现列表不动时立即识别边界，也未限制只搜索黄金所属车辆区间。

本版加入 J50 缺油分支：详情车型、燃油 0/ 前缀、右下跳过文字、左上返回箭头同时命中时，点击左上返回，确认选车列表的标题和段位导航条后结束。完成判断不要求仅拥有开启或黄金选中。最后节点 J50测试_缺油已返回。绝不点击跳过按钮，不执行补油或开赛。此节点用于后续换车衔接，当前尚未继续找下一辆。

已有开始按钮的 J50 详情继续执行 TouchDrive 确认。当前缺油模板来自 J50 的 0/5，实际检查裁出的 0/ 前缀，没有完整燃油数字读取；其他容量、开关状态、车型、回充中等外观仍需验证。没有不可用车型详情分支、完整轮换或非目标车辆详情页返回恢复。

## 实测

刷新 Maa Pipeline Support 任务列表，单独运行此任务：

1. 从黄金起点运行，确认自动滑动并进入 J50 详情。
2. 从 J50 完整可见列表运行，任务仍先点黄金回起点再搜索。
3. 从 J50 详情且 TouchDrive 关闭运行，应只开启开关并结束。
4. TouchDrive 已开启的 J50 详情运行，应保持原地。
5. 在缺油 J50 详情运行，应点击左上返回，停在黄金选车列表；不要点击跳过或进行补油。列表返回识别需设备实测。

有油状态结束节点 `J50测试_TouchDrive_已开启`。J50 搜索及开关路线用户已确认实测成功，新增缺油返回分支仍需实测。失败时提供当前完整框架截图和最后命中节点。模板源 24 张截图的列表身份、详情、缺油分支离线检查及全部配置校验已通过。
